# Slides QC rationale

Use this for any Slides rating task: a deck task (.pptx files, axes plus Overall) or an outline task (text outlines, Content Quality and Storytelling only).

## Follow the task instructions strictly

The task page's own instructions come first. Read them word for word before scoring and obey every one of them, even where this skill or habit would do something else.

- Read the Instructions, User request, input files list and the full rating form before opening any response.
- Rate the axes the form actually lists, in the form's order, using the form's own definition of each axis. If the form adds an axis (for example Editability) or drops one, follow the form.
- If the instructions say "Download every file shown in each response column before rating", open every file before writing anything.
- If the instructions say "Rate each response independently", each response's axis boxes and Overall box must stand completely on their own:
  - Never mention another response.
  - Never use comparative or ranking words about the deck: "the most complete", "the least visual", "of the three", "better", "stronger", "weaker", "unlike", "compared with", "the best".
  - Judge each deck only against the brief, the input files and the axis definition.
  - Do not set a score by looking at the other decks' scores.
  - Comparisons go only in the Overall Ranking box, after every response is fully rated.
- Use the labels and wording the form uses (for example "Explain the content quality rating", "What drove the ranking? Note ties or close calls.") so each answer fits the box it goes in.
- Treat file names and response labels as neutral, as instructed.
- If an instruction is unclear or a file is missing, say so and ask Olont before scoring. Do not guess.
- Before handing over, re-read the instructions once more and check every answer against them.

## Task order

1. Read the instructions, brief and rating form, and open every input file (user request, letters, memos, data packs, images, templates).
2. Open every response file.
3. Set the artifact status only when there is a downloadable file: did it open cleanly or need repairing?
4. Rate each response on its own: score each axis 1 to 7 and explain it.
5. Give that response's overall rating. It is weighted, not averaged. Say which axis decided it.
6. Only after all responses are rated, rank them. Say what drove the order and note close calls.

For an outline task, score only Content Quality and Storytelling. No slides were rendered, so there is nothing visual to score. Do not penalise the [source citation] marker.

## Rules for every rationale (QC deck page 2 and page 27 checklist)

- Judge against the task files only. Do not fact-check online.
- Cover every part the playbook lists for that axis, good and bad.
- Name the slide for every point and quote the wording being judged. "Some flowery wording" is not a finding.
- Score each problem on the axis it affects. If it also affects another axis, explain that impact there separately.
- Each rating judges one response on its own. Comparisons go only in the ranking.

## Only write what a human grader can see

- Every point must be something a person can confirm by opening the slides (including speaker notes) and looking.
- Do not name font families, colour hex codes, exact pixel or point measurements, or anything read from the file's code, unless it is printed on the slide or named in a task file.
- Rough figures are enough. Say what looks tight, small or uneven and name the slide.
- If my own rendering differs from how the deck opens in PowerPoint (for example, missing fonts making text look cut off or overlapping), do not report it as a defect. Ask Olont to check it in his viewer first.

## Axis checklist

### Content Quality (complete, accurate, true to source)
- Completeness: does it cover the key concepts the brief and sources need, and the slide count asked for? Check every requirement in the brief and every input file one by one. Is anything important left out, or anything irrelevant added?
- Accuracy: match the whole sentence to its source line, not just the number. A claim either matches the source, changes its meaning, or adds something the source never says.
- Omissions: a gap counts only if it is required (named in the brief, or a key point in the sources) and absent from every slide. If leaving it out makes the reader believe something the sources don't say, call it a misleading omission.
- Additions: flag anything that contradicts the files or goes past them with no source line. General background is fine without a source, but a figure or finding about the topic that the files don't give is missing evidence.
- Usefulness: does the audience gain something useful or something they can act on?
- Missing a major idea is enough for a low score.
- How well it is written belongs under Writing Style.

### Storytelling (one narrative, not a list of facts)
- Narrative, structure and transitions: does the deck tell one story in a logical order, with each slide picking up where the last one left off? Name the weak joins.
- Build-up: does every slide move the deck closer to its point? Does the evidence prove the claim beside it?
- Engagement: does the deck hold attention? Check it against any engagement or pacing need stated in the brief (session length, activities, too much information).
- Titles: you should be able to follow the argument from the titles alone.
- A wrong number or missing evidence is Content Quality. How the chart looks is Aesthetics.

### Writing Style (clear and specific, no buzzwords)
- Clarity, Conciseness, Specificity, Naturalness for the audience in the brief.
- AI slop: generic, inflated, repetitive, buzzword-heavy or formulaic language. Always quote the line.
- Quote the lines that work as well as the ones that don't.

### Aesthetics (type, colour, consistency, visuals)
- Typography and colour use: readable fonts, including the smallest text; palette suited to the audience, the template and any supplied logo or brand.
- Visual consistency: does every slide follow the same style? Look for a slide that breaks the pattern.
- Visual variety: do the visuals vary enough to hold interest?
- Visual quality: are charts, diagrams and images sharp, labelled and on palette?
- How an element looks belongs here. Where it sits and its spacing belong under Layout.

### Layout (spacing, alignment, no clutter)
- Spacing: room at the edges and between elements, including footers close to the edge.
- Alignment: titles in the same spot, edges line up.
- Grouping: related elements sit together.
- Hierarchy: the most important point is seen first.
- Clutter and overlap: nothing crammed or overlapping.

### Editability (only when the form lists it)
- Are text, charts and shapes real slide objects that can be edited, moved and updated, or are they flattened images?
- Are there placeholders left to fill in, or content locked inside a full-slide picture?

### Overall (holistic)
- Weighted, not averaged. One serious weakness can pull the rating down. Say which axis decided it.
- Readiness for the audience and setting in the prompt.
- Revision needed: a few small fixes, a solid amount of rework, or a full rebuild. Name the main fixes.
- No comparison with other responses here.

## Writing it in Olont's voice

The rationale must read as if Olont wrote it himself. Match his December trip ratings:

- Plain, simple English. Short declarative sentences. Phrases he uses: "The deck shows...", "Slide 5 shows that...", "This shows that...", "which aligns with...", "which contradicts...", "speaks to", "However,", "Similarly,", "Also,".
- First person only where needed ("I checked...").
- Keep it short. Use 1 or 2 examples per point, never 3 or more. One example is enough when it makes the point.
- Focus on the key attributes. Only write a point for a sub-criterion when there is something worth saying, and it is fine to combine labels the way he does ("Typography and colour use", "Narrative, structure and transitions", "Hierarchy and grouping").
- No em dashes, no slogans, no fancy phrasing, no long build-up sentences.

Format per axis:

**Axis name**
Rating: N (add the label, e.g. "6 — Very good", only if the task shows labels)
Sub-criterion: One to three plain sentences naming the slide and quoting the wording or figure, then the effect. e.g. "Slide 5 shows that Peru cost the least, which contradicts the cost sheet figures."

Optional score line: the QC deck's worked examples (pages 15, 17, 20, 23 and 26) end with a line like "Aligned, grouped and clearly ordered, so not a 4. A tight footer and two crowded slides, so not a 6." This is an example pattern, not a rule. Leave it out by default to match Olont's style, and add it only if he asks.

Overall: a short paragraph of two to four sentences. Start with "[Axis] decided this rating.", then what was strong, what held it back, and the revision needed.

Ranking: "Rank 1: Response X. Rank 2: Response Y." then a short paragraph starting "[Axis] determined this ranking.", what each response covered or missed, and any close calls.

## Final check before submitting

- I re-read the task instructions and every answer obeys them.
- Every axis the form lists is rated, in the form's order.
- Each response's boxes stand alone: no other response named, no comparative words (most, least, of the three, better, unlike).
- Every point names a slide.
- Every Writing Style point quotes the wording.
- Task files only; nothing fact-checked online.
- Only things a human can see by opening the deck.
- One problem, one axis (with any cross-axis impact explained separately).
- No point uses more than two examples.
- Overall names the deciding axis, readiness, and the revision needed.
